# Bend2Craft

Bend2Craft is a small Minecraft-inspired voxel sandbox built around Bend 2 and a dependency-free WebGL browser client.

Repository: https://github.com/lennix1337/bend2craft

## Architecture

Bend 2 is the source of truth for world dimensions, terrain heights, tree placement, block IDs, damage, hunger and mob stats. The browser layer materializes that contract into a voxel buffer, handles input and session inventory, and renders visible faces with WebGL 1. Terrain generation is not duplicated in JavaScript.

The Bend 2 compiler is pinned as the `vendor/bend` submodule. Bend 2's JavaScript target does not provide graphics, and native support on Windows is not available yet, so the development toolchain runs through WSL while the final game runs in the browser.

## Current slice

- Deterministic `48 x 48 x 20` voxel world.
- Minecraft-style title screen: Singleplayer, world list, create-world form and options.
- Create worlds with a name, a numeric or text seed (empty is random), a game mode and a difficulty.
- Survival, Creative and Hardcore modes with Peaceful/Easy/Normal/Hard difficulties.
- Rolling terrain generated by Bend 2.
- Deterministic trees with wood trunks and leaf canopies.
- First-person camera, WASD movement, mouse look, jumping and sprinting (Shift or double-tap W, with FOV kick).
- Health (20) and hunger (20) with heart and hunger bars, fall damage, starvation, regeneration and death screens.
- Apples drop from leaves and restore hunger; hardcore deaths delete the world.
- Pigs wander, graze and flee; they drop pork. Zombies chase at night, hit back and burn in daylight.
- Pixel-art mobs with animated legs, swinging zombie arms, snouts and faces from a procedural texture pack.
- Full day/night cycle with sunsets, stars, a square sun and moon, and darker nights.
- Animated title panorama orbiting a live-generated world behind the menus.
- Break, landing and eating particles plus footstep sounds.
- Creative mode with unlimited blocks and double-tap Space flying.
- AABB collision, block raycast with highlight, block removal and block placement.
- Nine-slot hotbar inventory with stack counts.
- Collecting a block adds it to the inventory; placing consumes one item.
- Worlds, options and block edits persist in localStorage.
- Procedural WebAudio sounds with a mute toggle.
- Bend laws and proofs for core world and survival invariants.

Block IDs:

- `0`: air
- `1`: stone
- `2`: dirt
- `3`: grass
- `4`: leaves
- `5`: wood
- `6`: apple (food, never placed)
- `7`: porkchop (food, never placed)
- `8`: rotten flesh (food, never placed)

## Windows + WSL setup

Clone the repository with its submodule:

```bash
git clone --recurse-submodules https://github.com/lennix1337/bend2craft.git
cd bend2craft
```

Install Bun into the project-local WSL tool directory when needed:

```bash
export BUN_INSTALL="$PWD/.tools/bun"
curl -fsSL https://bun.sh/install | bash
```

The project scripts automatically prefer `.tools/bun/bin/bun`.

## Commands

Run these commands from WSL at the repository root:

```bash
npm run verify       # all Bend, proof, test, build and diff checks
npm run check:bend   # type-check world/world.bend
npm run proof        # verify LAWS.bend and PROOF.bend
npm run test         # world, inventory and game-state regression tests
npm run dev          # start the Bun development server
npm run build        # create the static bundle in dist/
```

Open the URL printed by Bun in a Windows browser.

## Development workflow

The pure player/world state lives in `web/game-state.js`, survival math in `web/survival.js`, the day/night cycle in `web/daynight.js`, mob brains in `web/mobs.js`, the pixel-art atlas in `web/textures.js`, dynamic meshes in `web/dynamic.js` and menu/mode rules in `web/settings.js`; all are tested without a browser. The DOM/WebGL adapter lives in `web/main.js`; validate it manually with `npm run dev` after passing `npm run verify`. Survival and mob rules mirror `world/survival.bend` and `world/mobs.bend`, which are the Bend 2 source of truth.

For a long-lived local server, keep the background process silent, check readiness once with `curl`, and stop it after the browser smoke test. This avoids stale readiness notifications after the server has been killed.

## Seeds

The default seed is `1337`. Open a specific numeric or text seed directly:

```text
http://localhost:3000/?seed=1337
http://localhost:3000/?seed=forest
```

The same seed produces the same heights, trees and block layout. Different seeds change the terrain and tree distribution while preserving the world dimensions and block contract.

## Controls

- `WASD`: move
- Mouse: look after clicking the canvas
- `Shift` or double-tap `W`: sprint (drains hunger, FOV kick)
- `Space`: jump (double-tap in Creative to toggle flying; `Space`/`Shift` move up/down while flying)
- `1` through `9`: select a hotbar slot
- Left click: attack the targeted mob, or remove the targeted block and collect it
- Right click: place the selected block if the stack has items, or eat selected food
- `E`: eat the selected food (apples drop from leaves)
- `Esc`: open the pause menu
- A `?seed=name` URL still works: it prefills the create-world seed field.

## Development rules

Read `AGENTS.md` before changing the project. Keep generation and block semantics in Bend, write a failing regression test before behavior changes, and run all four commands above before publishing changes.
